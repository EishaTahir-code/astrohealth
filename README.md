# Orbloom

A calm, offline-first health companion for astronauts on long missions, with a shared crew garden.

- Live app (after GitHub Pages is switched on): https://eishatahir-code.github.io/astrohealth/
- How to run it, the sample accounts and what changed: [PROGRESS.md](PROGRESS.md)
- How it is built: [TECH.md](TECH.md) · What it should do: [PRD.md](PRD.md)

```bash
npm run setup   # first time
npm run dev     # then open http://localhost:5173
```
